# Sumatif 2 GCT

Recap kuliah K10-K20 Modul Ginjal dan Cairan Tubuh dan bank soal Sumatif 2 (2019-2023) dengan jawaban, slide pendukung, dan tautan sumber.

Buka `index.html`, atau aktifkan GitHub Pages (Settings, Pages, branch `main`, folder root).

- `index.html`: isi halaman
- `recap.css`: tampilan
- `recap.js`: interaksi (jawab soal, reset, perbesar gambar)
- `img/`: gambar slide dan gambar soal
