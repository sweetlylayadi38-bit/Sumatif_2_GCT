# Sumatif 2 GCT

Recap kuliah K10-K20 Modul Ginjal dan Cairan Tubuh dan bank soal Sumatif 2 (2017-2023) dengan jawaban, slide pendukung, dan tautan sumber. Ada juga rangkuman kuliah dengan mnemonik (bagian Rangkuman + Mnemonik), blok mnemonik di akhir tiap kuliah, dan mnemonik di setiap pembahasan soal. Bagian Slide paling sering keluar mengurutkan halaman slide menurut jumlah soal Sumatif 2 yang memakainya; tiap halaman bisa dibuka langsung lewat tautan `#sl-<kuliah>-<halaman>`, misalnya `#sl-k20-radiologi-34`.

Buka `index.html`, atau aktifkan GitHub Pages (Settings, Pages, branch `main`, folder root).

- `index.html`: isi halaman
- `recap.css`: tampilan
- `recap.js`: interaksi (jawab soal, reset, perbesar gambar, buka rangkuman, layar slide prioritas dengan tombol berikutnya)
- `img/`: gambar slide dan gambar soal
