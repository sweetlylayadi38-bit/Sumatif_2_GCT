# Sumatif 2 GCT

Recap kuliah K10-K20 Modul Ginjal dan Cairan Tubuh dan bank soal Sumatif 2 (2017-2023) dengan jawaban, slide pendukung, dan tautan sumber. Ada juga rangkuman kuliah dengan mnemonik (bagian Rangkuman + Mnemonik), blok mnemonik di akhir tiap kuliah, dan mnemonik di setiap pembahasan soal.

Buka `index.html`, atau aktifkan GitHub Pages (Settings, Pages, branch `main`, folder root).

- `index.html`: isi halaman
- `recap.css`: tampilan
- `recap.js`: interaksi (jawab soal, reset, perbesar gambar, buka rangkuman)
- `img/`: gambar slide dan gambar soal
